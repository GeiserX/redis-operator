# CLAUDE.md — Redis Operator

## Overview
A Kubernetes Operator (proof-of-concept) that manages single-node Redis instances via Custom Resources, with automated password generation, health monitoring, and clean-up via OwnerReferences.

## Tech Stack
- Go
- Kubebuilder / controller-runtime
- Kubernetes CRDs (v1.26–v1.33)
- Docker (image: `drumsergio/redis-operator`)

## Development
```bash
make generate        # regenerate CRD manifests
make manifests       # generate RBAC and CRD YAMLs
make test            # run unit tests
make docker-build IMG=docker.io/<user>/redis-operator:<tag>
make deploy IMG=docker.io/<user>/redis-operator:<tag>
```

## Architecture
- `api/` — CRD type definitions
- `internal/controller/` — reconciliation logic
- `cmd/` — operator entrypoint
- `config/` — Kubernetes manifests (CRDs, RBAC, deploy)
- `hack/` — development scripts
- `test/` — integration/e2e tests

## Key Rules
- Never hardcode credentials; operator auto-generates Redis passwords into Secrets
- Docker images use semver tags, never `:latest`
